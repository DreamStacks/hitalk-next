# 维护说明

本轮目标是让现有评论能力可验证、可升级、可维护。保留 Hono、D1、原生 DOM SDK 和现有邮件插件，不引入 UI 框架或通用存储抽象。

## 边界

- `packages/shared` 定义公开类型和 Valibot 运行时校验；前后端共用邮箱/网址规则，后端验证完整请求。SDK 按需内联代码，发布声明不引用 workspace 或 Valibot 内部类型。
- `apps/server/src/types.ts` 保存内部数据库与插件类型。SQLite 数字布尔值在 `publicComment()` 中转换为 boolean。
- 公开评论经过显式字段映射。邮箱只供内部通知使用，不采集评论 UA/IP。IP 摘要只在点赞记录中用于去重。
- 路由负责运行时输入校验、认证与错误状态。TypeScript 类型不替代输入验证。
- 只持久化 Markdown 原文，在公开输出和邮件中使用同一个安全渲染器生成 HTML；没有需要同步维护的 HTML 缓存。
- 邮件钩子只保留已使用的 `onCommentCreated`，上下文有明确类型；错误隔离在插件调用处。邮件仍是尽力发送，不声称可靠投递。

## 数据规则

页面路径唯一，一个 Worker 对应一个站点。页面在首次有效提交时创建，读取不写库；后续匿名提交不会覆盖已有标题。

回复必须位于父评论所在页面；数据库同时检查归属与最大链长 8 条（含根评论）。真实 D1 对深链级联删除的限制比 Node SQLite 更严格；最大深度测试包含最底层点赞、根评论删除和页面删除。`id / page_id / parent_id` 不允许更新，阻止环和跨页面移动。列表按根评论分页，将选中讨论串中的后代平铺为第二层；原始 `parent_id` 保留回复关系。

删除会删除目标评论的全部后代及其点赞。评论/点赞计数均由同一 SQL 写入触发的数据库触发器维护。点赞依赖 `(comment_id, ip_hash)` 唯一约束，重复请求不会累计；D1 batch 将插入和结果查询放在同一事务中。

## SDK 生命周期

Store 只在评论列表数据变动时通知列表渲染。昵称缓存和回复目标变动不再触发全列表重绘。点赞同步到 Store；比点赞更早发起的列表请求不会覆盖刚确认的点赞结果。

编辑器是长期持有的节点。列表替换前先移出编辑器，完成后按回复目标放回，保留草稿与焦点。无法找到目标时退回顶层编辑器。

请求有超时和实例级取消；列表请求有顺序标识，过期响应不能覆盖新结果。提交与单条点赞有进行中保护。存储不可用不影响提交成功。错误以文本显示，加载失败可以重新加载。

`destroy()` 清理请求、订阅、全局事件监听与 DOM。同一容器再次 `mount()` 会先销毁旧实例。用户字段插入 HTML 属性前统一转义，网址单独校验协议。只有服务端生成的 `content_html` 作为可信 HTML 插入，因此 SDK 应连接可信的 Hitalk API。

## 验证

`pnpm check`：类型感知 Oxlint（零警告）、Oxfmt、TypeScript 7 类型检查、tsdown 构建、Vitest 与 Istanbul 覆盖率门槛。后端通过官方 Cloudflare 插件在 workerd/D1 中运行；每项测试显式清理数据，避免测试文件内存储相互影响。SDK 主要测试源码，另检查 IIFE 实际产物、ESM 导出及脱离 workspace 的声明编译。Node SQLite 只用于备份可恢复性测试。

测试配置明确构造本地 D1 及假令牌，不加载开发 `.env` / `.dev.vars`，邮件请求仅在单项测试中 mock。

`pnpm test:worker`：在临时目录应用迁移两次，运行本地 Worker 与真实 D1 绑定，验证请求链路和并发点赞，再用 Wrangler 导出 SQL 并恢复至临时 SQLite 检查关系、计数、环与触发器。现有本地和生产数据不参与该测试。

CI 还进行 Worker dry-run 打包。源码构建检查不等于生产部署验证；真实邮件、生产配置和真实浏览器兼容性仍需部署环境验收。

## 暂缓与已知限制

- 匿名写入的频控、验证码、审核还未实现；公开 CORS 是嵌入式公共 API 的配置，不是防刷机制。
- 邮件没有持久队列、重试、退订和投递审计。不要把返回 201 当作邮件已送达。
- 分页以根评论为单位；单个大讨论串仍会一次加载全部回复。offset 分页在并发插入/置顶时可能移动边界，SDK 去重，但严格稳定分页需后续游标设计。
- Gravatar 摘要不等于匿名身份，邮件仍以明文存于私有数据库。对头像和表情 CDN 的请求会交给第三方。
- 同一 IP 的访客共享点赞限制；本地未提供 Cloudflare IP 时使用共同标识，不采用访客可伪造的 X-Forwarded-For。
- 管理令牌是静态共享密钥，不是多用户权限系统。管理页只在内存保存令牌，刷新需重新登录。
- 国际化、登录和更多插件暂缓。不承担旧版本兼容或数据迁移。

下一阶段应在自己的博客做小范围试运行，观察真实错误和数据量，再决定是否需要更复杂的架构。
