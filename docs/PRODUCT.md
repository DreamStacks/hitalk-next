# Product

## Register

product

## Users

Hitalk 面向自托管博客作者与留言读者。examples/playground 是项目维护者在本地检查评论、回复、表情和主题的交互示例。

## Product Purpose

提供轻量、可嵌入的评论系统。开发示例直接运行 SDK 与本地 Worker，让真实交互可见、可验证。

## Brand Personality

简约、清新、亲切，带一点旧版的可爱感。保留薄荷绿与阅读留白，融入旧版输入框插画、颜文字、虚线和少量粉色点缀。设计范围为开发示例页。

## Anti-references

避免现有示例里的重背景光效、噪点、密集功能宣传和与评论体验无关的外部挂件。

## Design Principles

- 评论输入与阅读是页面中心。
- 示例使用真实 SDK，不伪造评论或连接状态。
- 开发页样式独立，宿主示例的视觉定制不改变发布 SDK 的默认外观。
- 保留主题切换与开发热更新。

## Accessibility & Inclusion

采用清晰文字对比、可见键盘焦点、可缩放页面、窄屏重排和减少动态效果支持。没有收到额外的无障碍约束。
