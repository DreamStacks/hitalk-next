# 架构与不变量

本版本按未上线项目重构，不维护旧 API、旧字段或旧 schema。保留 Hono/Workers/D1、TypeScript/lit-html；不引入 ORM、Redis、账户密码、验证码或独立消息服务。

## 模块

- packages/shared：唯一公开契约和 Valibot 输入校验。
- server/routes：HTTP 参数、权限、错误映射和响应。
- server/services/comments：身份创建、幂等写入、删除、点赞、审核及原子通知入队。
- server/services/notifications：持久任务、租约、固定投递载荷、退避、退订。
- server/lib/db：分页、可见性、公开投影、批量装饰；只读查询不创建页面或身份。
- server/lib/auth：凭证摘要、身份识别、管理令牌和基本频控。
- SDK identity/api/store：持久匿名凭证、请求取消与类型化错误、评论状态。
- SDK index/ui/renderer：生命周期、草稿、请求标识、局部合并、回复定位和模板。

## 身份

32 字节 Web Crypto 随机 token，在首次写入前持久保存。服务端按 SHA-256 摘要查找身份。未知 token 仅在有效评论或首次点赞的原子写入中注册；blocked 身份绝不重新注册。公开接口不返回作者内部 ID 或凭证摘要。

凭证是访客权限的持有者证明，不证明真人或邮箱所有权；基础频控同时按身份和可信来源 IP 摘要执行。管理身份是预置的 site-owner，仅管理路由可使用，不由客户端输入决定。

Web Locks 将同源多个标签页的首次 token 初始化串行化。存储键包含 API 地址；不同浏览器、宿主 origin 或 API 地址身份不共享。localStorage 可被宿主脚本读取，宿主 XSS 属于信任边界；本系统不声称有 HttpOnly 的防读取属性。

## 回复与删除

comments.seq 为 SQLite 单调序号，id 为公开 UUID。根评论 root_id/reply_to_id 均为空；回复 root_id 永远指向同页根评论，reply_to_id 指向已存在、同串、可见、未删除的实际目标。数据库触发器验证关系并禁止修改身份与结构字段。

查询不递归遍历祖先；任意回复可继续被回复，没有 8 层限制。根节点及直接回复引用不做 ON DELETE CASCADE；业务删除保留行并清空正文、昵称、邮箱、网址、UA、通知偏好和点赞，取消相关待发送任务并清除其载荷/收件人。其他人的回复不会消失。

公开计数和点赞数从真实关系计算，不维护重复的计数字段。visible_comments 视图定义有效正文：自身 published 且未删除，并且根处于 published。已删除根可作为存量回复的占位，但不接受直接回复；仍可回复该串中其他有效回复。

隐藏根隐藏全串；隐藏某条普通回复不隐藏后续回复，被引用摘要变为不可用。恢复根不改变子评论独立审核状态。公开根列表只展示有正文或至少一条可见回复的讨论串。

## 幂等和写入

comments UNIQUE(author_id,client_request_id)，request_hash 绑定规范化业务字段。并发重复请求通过数据库唯一约束收敛，相同标识不同载荷返回 409。身份、页面、评论和通知记录在 D1 batch 中提交，任一步失败回滚；没有跨请求的进程内锁。

软删除保留请求 ID/摘要，因此旧请求永久不会复活已删除内容。评论不支持直接编辑，避免未设计的编辑审核、版本与通知语义；作者可以删除后重新发布。

## 读取和状态

根列表/回复分别使用降序/升序 sequence 游标，作用域绑定页面/根；创建水位限制新写入进入当前分页。置顶独立查询、最多 5 条，普通流仍包含原来的排序位置，SDK 去重。审核/删除可在分页期间变化，游标不是完整数据库快照。

预览最多 3 条，定位返回预览和一个额外目标，避免定位尾部后失去较早回复的加载入口。SDK 按 sequence 合并回复，保留正在编辑的 DOM、焦点和草稿；列表加载使用序号及写入修订号，旧响应不能覆盖已确认操作。

待审核回执与公开评论分开存储/展示。作者从私有接口取最近 20 条待审核记录，不计入公开总数。公开内容允许不带凭证读取；带访问者状态的响应统一 no-store。

## 通知

首次公开时原子入队；任务对评论/收件人唯一。Worker scheduled 每分钟执行，waitUntil 可加速。条件更新领取租约，完成时再次匹配租约 token，防止过期执行者覆盖新执行者。

首次尝试持久化固定 Resend 载荷，重试不因站点配置变更而更改同一个幂等键的载荷。使用固定任务键，最多 8 次，首次尝试后最多 23 小时；429/5xx/网络未确认退避重试，永久失败进入 failed。服务商接受不代表实际投递确认。

发送前检查当前可见性、被回复者通知偏好及抑制列表；删除、隐藏、退订取消尚未发送的任务。已经进入第三方网络调用的邮件无法撤回。EMAIL_ENABLED 默认关闭；未配置投递依赖时任务保留等待，不依靠请求生命周期可靠发送。

## 验证责任

自动化覆盖真实 D1 数据完整性、并发幂等、权限、作用域游标、1,000 回复有界读取、通知租约和失败恢复、SDK 请求竞态、持久身份、草稿/回执、销毁及发布产物。视觉、布局、主题与实际宿主观感由用户验收。
