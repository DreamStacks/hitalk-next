# 当前实现范围

更新日期：2026-09-18。按未上线项目重构，使用新 schema 和唯一 /api 协议，不保留历史兼容逻辑。

已实现：

- [x] 本地示例默认连接本地 Worker；使用独立本地数据库标识。
- [x] 浏览器持久匿名身份，服务端摘要存储，多标签页初始化协调。
- [x] 作者删除自己的内容，保留他人回复；按身份点赞/取消点赞。
- [x] 评论创建幂等、并发首次身份创建、超时重试及删除后重放。
- [x] 平铺线程模型、根/回复游标分页、有限预览和按需定位。
- [x] 审核、隐藏、垃圾标记、作者待审核回执、页面开关及身份封禁。
- [x] 基础身份/IP 频控，不使用验证码。
- [x] D1 持久通知任务、租约、固定载荷、失败重试、退订和取消。
- [x] SDK 请求取消、草稿/请求标识恢复、局部合并及迟到响应保护。
- [x] 管理端、真实 D1 测试、发布产物与备份检查同步采用新模型。

用户负责：视觉与真实博客观感验收。

部署前配置：新的生产 D1 ID、管理令牌、IP 盐、前端 API 地址；需要邮件时显式开启并配置 Resend、站点与 API URL。

当前不包含：密码账户、邮箱认领身份、跨设备同步、作者编辑历史、文件上传、举报工作流、多租户、完整投递回执跟踪。
